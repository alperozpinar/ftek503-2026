# FTEK 503 Finansal Programlama (Güz 2026)

İbn Haldun Üniversitesi, Finansal Teknolojiler Yüksek Lisans Programı. Dersler her Salı 13:30-16:30.

Bu repo dersin öğrenci materyallerini içerir: haftalık ders notları, alıştırma Excel dosyaları, Colab defterleri ve Finans Temeli El Kitabı. Materyaller haftalık olarak eklenir.

## Nasıl kullanılır

- **Excel dosyaları:** Dosyayı açın, sağ üstteki indirme düğmesiyle bilgisayarınıza kaydedin ve masaüstü Excel'de açın (İHÜ Microsoft 365 hesabınızla kurulur). Sarı hücreler sizin dolduracağınız yerlerdir.
- **Colab defterleri:** Haftanın sayfasındaki "Open in Colab" bağlantısıyla açın, ardından **Dosya > Drive'a kopya kaydet** ile kendi kopyanızı alın. Kopya almadan yaptığınız değişiklikler kaydedilmez.
- **Ders notları ve el kitabı:** GitHub'da doğrudan okunur.
